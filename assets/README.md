# Assets

This directory contains auto-generated SVG stats cards and media assets.
Files in this directory are updated daily by GitHub Actions.

- `github-stats-dark.svg` / `github-stats-light.svg` — GitHub Stats cards
- `top-languages-dark.svg` / `top-languages-light.svg` — Most Used Languages charts
- `github-streak-dark.svg` / `github-streak-light.svg` — GitHub Streak Stats cards
- `windows-printer-sharing-fix-dark.svg` / `windows-printer-sharing-fix-light.svg` — Pinned repo cards
- `waretricks_banner_final_dark.png` / `waretricks_banner_final_light.png` — Banner images for WareTricks Portal
- `cliviaid_banner_dark.png` / `cliviaid_banner_light.png` — Banner images for clivia.id Store & Catalog
